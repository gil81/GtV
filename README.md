# GtV

GtV is a custom Android TV media frontend based on Wholphin.

## Features

- Jellyfin integration
- New Release Movies home row
- New Release TV home row
- Dynamic Library integration
- TV seasons and episodes
- Streaming playback
- Android TV / Google TV support

## Current Status

Active development and personal testing.

## Project

GtV is being customized as a unified TV frontend with a focus on a clean Android TV experience and fast access to both movies and TV.
